## Overview

이 문서는 템플릿 작성·사용·라우트·네이밍과 Templater 엔진 설정을 담당한다. ZotLit은 선택이며 이 템플릿에 포함되지 않는다. 도구 역할, 플러그인 설치 확인, 플러그인 관리 속성, 캡처 라우팅, taxonomy 동기화는 [[04. Applications and Integrations]]가 담당한다. 작성은 [[00. Guideline Authoring]]과 [[guideline.template]]을 따른다.

```text
Templates
├── Template System — Templater routes `02 Templates/{manual,auto,zotero}` + observed extra dirs
├── Engine Config — Templater 관측 설정 (이 템플릿의 shipped config)
├── Naming and Placement — `*.template.md` / Eta / 관측 디렉터리 보존
└── Use — manual 실행 vs auto 분리
```

## Map

### Template System

- **Templater 배치 루트는 아래 3분류다.**
	- 그 옆의 추가 디렉터리는 관측 계약이다. `obsidian web clipper/`와 `software-design-docs/`는 선택이며 후자는 이 템플릿에 포함되지 않는다.
	- 새 Templater 라우트가 아니다.
	- 파일을 옮기거나 3분류로 흡수하지 않는다.

**Templater 배치 루트** (`90. Settings/02 Templates/`):

| 카테고리 | 폴더 | 용도 (관측) |
|---|---|---|
| Manual | `02 Templates/manual/` | 사용자가 Templater(`cmd+t`)로 고르는 `*.template.md` |
| Auto | `02 Templates/auto/` | 주기 노트·대시보드용 Templater `*.template.md` |
| Zotero | `02 Templates/zotero/` | ZotLit Eta 템플릿 (`zt-*.eta.md`) |

- Manual: `templater-obsidian`의 `templates_folder`는 `90. Settings/02 Templates`다. `cmd+t` 모달은 그 아래에서 `manual/`을 고른다.
- Auto: Daily/Weekly/Monthly/Quarterly/Yearly와 Dashboard.
	- 폴더와 문법이 계약이다.
	- 자동 적용은 Templater `folder_templates`다. Periodic Notes 플러그인을 가정하지 않는다.
	- Core Daily Notes는 켜져 있다. 설정은 [[#Engine Config]]를 본다.

**관측된 추가 디렉터리** (Templater 배치 루트 아님. 현 위치 보존):

| 카테고리 | 폴더 | 관측 계약 |
|---|---|---|
| Agent | `02 Templates/agent/` | 에이전트 인제스트·세션 산출물용 `*.template.md`. 치환은 `{{ }}`. Templater `templates_folder` 밖. |
| Web Clipper (optional, not a Templater category) | `02 Templates/obsidian web clipper/` | Obsidian Web Clipper JSON (`*-clipper.json`). 이 템플릿은 선택 폴더로 두며 ZotLit처럼 엔진에 묶지 않는다. |
| Software design docs (optional, not shipped) | `02 Templates/software-design-docs/` | 채택자가 쓰는 5-node MECE 설계 문서 폴더. 이 템플릿에는 포함되지 않는다. |

> [!warning] 폴더명은 `02 Templates`
> Templater 루트는 `90. Settings/02 Templates/`다. 경로를 쓰기 전에 디스크와 [[01. Folders and Placement]] Naming Pattern을 확인한다.

### Naming and Placement

- **새 Templater 템플릿은 3분류 안에서만 배치한다.**
	- 카테고리(manual/auto/zotero)를 판정한다.
	- 해당 하위 폴더에 둔다.
	- `*.template.md` 이름을 쓴다.
	- 감사 면제 대상은 [[02. Properties]] 감사 면제 목록을 참고한다.
	- 관측된 추가 디렉터리로 보내거나 거기서 꺼내는 배치는 이 문서가 만들지 않는다.

### Engine Config

- 아래 값은 이 템플릿의 shipped config에서 관측한 것이다.
	- 설치 여부와 설정 ID는 [[04. Applications and Integrations]]가 담당한다.
	- 이 문서는 플러그인 설정 파일을 편집하지 않는다.

| 플러그인 | 역할 | 관측된 설정 | 설정 파일 |
|---|---|---|---|
| Templater (`templater-obsidian`) | 템플릿 엔진 | `templates_folder` = `90. Settings/02 Templates`; `trigger_on_file_creation_mode` = `folder` | `.obsidian/plugins/templater-obsidian/data.json` |
| Core Daily Notes | 일일 노트 폴더·파일명 | `folder` = `10. Time/01 Daily Notes`; `format` = `YYYY-MM-DD`; `autorun` = false. `core-plugins.json`에서 `daily-notes`: true | `.obsidian/daily-notes.json`, `.obsidian/core-plugins.json` |
| ZotLit (`zotlit`) (optional, not shipped) | Zotero 문헌 import 템플릿 | 이 템플릿은 ZotLit 플러그인과 `zotlit/data.json`을 포함하지 않는다. `02 Templates/zotero/`는 빈 카테고리로 둔다 | — |

Templater `folder_templates` (이 템플릿의 shipped config):

| folder | template |
|---|---|
| `10. Time/01 Daily Notes` | `90. Settings/02 Templates/auto/Daily Note.template.md` |
| `10. Time/02 Weekly Notes` | `90. Settings/02 Templates/auto/Weekly Notes.template.md` |
| `10. Time/03 Monthly Notes` | `90. Settings/02 Templates/auto/Monthly Notes.template.md` |
| `10. Time/05 Quarterly Notes` | `90. Settings/02 Templates/auto/Quarterly Notes.template.md` |
| `10. Time/04 Yearly Notes` | `90. Settings/02 Templates/auto/Yearly Note.template.md` |

- `enabled_templates_hotkeys`는 비어 있다. Dashboard는 `auto/Dashboard.template.md`로 두되 `folder_templates`에는 없다.
- **Periodic Notes를 auto 템플릿의 자동 적용 엔진으로 쓰지 않는다.**
	- 설치 관측은 [[04. Applications and Integrations]]를 따른다.
	- `auto/` 폴더와 Daily Notes 설정을 Periodic Notes 설치 증거로 쓰지 않는다.

### Use

- **`manual/`과 `auto/`의 분리는 엄격히 유지한다.**
	- 이 규칙은 Templater 3분류에만 적용한다.
	- auto 템플릿을 `manual/`에 두면 Templater(`cmd+t`) 모달이 지저분해지고 사용자가 혼란을 겪는다.

## Rules

- **OMS reuses the matching existing Obsidian template.**
	- Do not create an OMS-only template folder or frame copy.
	- Report missing or unsupported rendering; do not bypass the template or invent an alternate frame.
- 새 Templater 파일을 두기 전에 카테고리가 `02 Templates/{manual,auto,zotero}`인지, 이름이 `*.template.md`인지 확인한다.
- `agent/`, `obsidian web clipper/`, `software-design-docs/`를 3분류로 흡수하거나 거기서 꺼내지 않았는지 확인한다.
- auto 템플릿이 `manual/`에 없는지 확인한다.
- 도구 역할·플러그인 설치·플러그인 관리 속성·캡처 라우팅·taxonomy 동기화는 [[04. Applications and Integrations]]를 따른다.

## Caveats

- **파일 번호는 우선순위가 아니다.**
	- 이 문서와 [[04. Applications and Integrations]]는 같은 4단계 운영 계층이다.
	- `15`는 `04`–`14`와 충돌하지 않기 위한 이름일 뿐, 새 우선순위를 만들지 않는다.
	- 폴더·속성·권한 계약과 충돌하면 양보한다.

- **Templater 루트는 `02 Templates`다.**
	- 경로를 쓰기 전에 실제 폴더와 [[01. Folders and Placement]] Naming Pattern을 확인한다.

- **ZotLit 관리 노트의 이동은 이 문서가 허가하지 않는다.**
	- ZotLit은 선택이며 이 템플릿에 포함되지 않는다. 채택자가 설치한 경우에만 적용한다.
	- 임의 이동 시 링크가 에러 없이 끊어질 수 있다.
	- 속성 계약은 [[04. Applications and Integrations]]의 plugin-managed properties를 따른다.

- **템플릿 사용은 플러그인 설정 변경을 뜻하지 않는다.**
	- 설치 확인과 `.obsidian/` 편집 금지는 [[04. Applications and Integrations]]를 따른다.
	- 산출 노트의 배치·속성·권한·문장 표현은 [[01. Folders and Placement]], [[02. Properties]], [[03. Agent Permissions and Workflows]], [[05. Writing Style]]을 따른다.

### Engine Configuration Snapshot

- **엔진 설정 관측은 이 템플릿의 shipped config다.**
	- `templates_folder`와 `folder_templates`는 `.obsidian/plugins/templater-obsidian/data.json`에서 관측한다.
	- Daily Notes는 `.obsidian/daily-notes.json`과 `.obsidian/core-plugins.json`에서 관측한다.
	- 채택자 볼트의 런타임 보증이 아니다. 사용 전에 해당 `data.json`을 다시 연다.
	- taxonomy 변경 시 해당 `data.json` 경로 키 감사는 [[04. Applications and Integrations]]를 따른다.
